## Bug Tracking

Project bugs should be recorded in `bugs.md`.

Each bug should include:

* Problem
* Assigned team member
* Status
* Notes
```text
Problem 1: Tunnel Exit status not working in Atal Tunnel
Assigned to: Member 2
Status: Pending
Notes: Check map configuration and API setup
```
```text
Problem 2: Project icon appearing in a box
Assigned to: Member 2
Status: Pending
Notes: Check map API setup
```
